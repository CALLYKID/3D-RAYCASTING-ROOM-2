# 3D Raycasting Platformer — Part 2
**My Terra Hack Club Project | 3D Raycasting Series**

Welcome to Part 2 of my 3D raycasting series for the Terra program!

This project takes my original raycasting platformer further, with custom textures, new movement mechanics, enemies, collectible stars, and an optional crosshair that lets you look around the environment in different directions.

This has been my biggest update so far. I've spent **over 20 hours working on the project**, with almost **1,100 blocks of code** put into making everything work.

##  How to Play

- **WASD / Arrow Keys:** Move around the platform.
- **Spacebar:** Jump over enemies.
- **Collect all 10 stars:** Try to find every star while avoiding the enemies.
- **Avoid enemies:** Touching an enemy triggers a red warning, so watch where you're going!

##  What's New in Part 2?

### Custom Textures
I've added custom textures to the raycasting environment to make the platforms look more detailed. Both platform sections have their own texture toggles, so you can experiment with different looks.

- **Press Y repeatedly** to cycle through the textures on the first platform section.
- **Press T repeatedly** for the second platform to change its appearance as well.

### Optional Crosshair
There's now an optional crosshair feature for looking around the environment.

To enable it:
1. Click **See Inside** on the Scratch project.
2. Find the `NOT` block associated with the crosshair toggle.
3. Move the `NOT` block into the adjacent `if` block to activate the feature.

Once enabled, you can use the crosshair to look around, including pointing upwards towards the ceiling or downwards towards the floor.

### Jumping and Enemy Interaction
The player can now jump using the spacebar, making it possible to get over enemies instead of simply navigating around them. Touching an enemy also triggers a red warning, giving the player feedback when they make contact.
