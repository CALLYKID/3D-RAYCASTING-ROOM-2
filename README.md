Terra Hack Club: 3D Raycasting Platformer (Part 2) 

This is the second part of my 3D raycasting project for the Terra program. I put over 20 hours of work into this version, pushing the project to nearly 1,400 blocks of Scratch code to bring everything together. 

Controls: 

* Movement: WASD or Arrow Keys
* Jump: Spacebar
* Objective: Collect all 10 stars while dodging enemies.

Major changes in this update: 

* Textures: Added custom textures to give the platforms more detail. Pressing Y cycles the first platform's texture, and pressing T cycles the second.
* Looking Around: Included a hidden crosshair feature. If you go inside the project, find the crosshair toggle, and move the NOT block into the adjacent IF block, you'll be able to look freely up, down, and around the environment.
* Atmosphere & UI: Replaced the basic setup with a clean main menu, functional Win/Lose screens, a sleek health bar, and a tunnel-vision effect. The enemies have also been redesigned to be much more intimidating.
